# Project one-line description

- Swiggy-clone — Single Page Application simulating a food-ordering platform built with React, client-side routing, and responsive Tailwind UI.

React, React Hooks, Functional Components, Custom Hooks, useState, useEffect, useParams, Context API, Redux Toolkit, RTK, react-router-dom, Client-side Routing, Parcel (bundler), Tailwind CSS, Utility-first CSS, Responsive Design, REST APIs, fetch/async, Shimmer/Loading Skeleton, Component-driven Architecture, Code-splitting, Lazy Loading, Higher-Order Components (HOC), Unit Testing, Integration Testing, Jest, React Testing Library, @testing-library/jest-dom, Babel, Git, GitHub, State Management, Performance Optimization, Accessibility.

- Built a Swiggy-like SPA using React and Parcel; implemented responsive UI with Tailwind CSS and component-driven architecture.
- Implemented client-side routing with react-router-dom and dynamic route params to fetch restaurant menus via REST APIs.
- Created reusable custom hooks for data fetching and state management; integrated Context API and Redux Toolkit for global state (cart/auth).
- Optimized UX with shimmer loading skeletons, code-splitting and lazy-loading to improve perceived load times.
- Wrote unit and integration tests using Jest and React Testing Library (including jest-dom) to ensure component reliability.
- Managed source control and CI-ready repo with Git/GitHub; followed best practices for keys, prop-drilling reduction, and single responsibility components.

## Tech: React, Redux Toolkit, Context API, react-router-dom, Parcel, Tailwind CSS, Jest + React Testing Library, REST APIs, Git/GitHub.
